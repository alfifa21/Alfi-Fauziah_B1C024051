A. Mengapa Evaluasi Model Tidak Cukup Hanya Menggunakan Accuracy?
Dalam mendeteksi kanker payudara, Accuracy saja tidak cukup untuk menilai apakah model sudah bekerja dengan baik. Hal ini karena:

1. Ketidakseimbangan Data: Jika sebagian besar data adalah pasien sehat, model bisa mendapatkan akurasi tinggi meskipun tidak mampu mendeteksi pasien yang terkena kanker.

2. Kesalahan Diagnosis (False Negative): Kesalahan menganggap pasien kanker sebagai pasien sehat sangat berbahaya karena dapat menyebabkan keterlambatan pengobatan.

3. Pentingnya Recall: Recall digunakan untuk mengukur kemampuan model dalam mendeteksi pasien yang benar-benar terkena kanker. Semakin tinggi nilai Recall, semakin sedikit pasien kanker yang terlewat oleh model.

Kesimpulannya, dalam mendeteksi kanker payudara, model tidak hanya harus memiliki Accuracy tinggi, tetapi juga Recall yang tinggi agar dapat mendeteksi sebanyak mungkin pasien yang terkena kanker.
